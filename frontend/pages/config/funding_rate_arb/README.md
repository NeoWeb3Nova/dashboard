# 💰 永续合约资金费率套利策略 (Funding Rate Arbitrage)

## 策略简介
资金费率套利（Funding Rate Arbitrage / Basis Arbitrage）是一种经典的 **Delta-Neutral（绝对中性）量化策略**。

### 核心运作原理
1. **多空完全对冲（零币价风险）**：
   - 机器人在 **交易所 A** 开多（Long），同时在 **交易所 B** 开等额的空单（Short）。
   - 不管代币价格暴跌 90% 还是暴涨 10 倍，两个仓位的现货/合约盈亏完全对冲抵消（净持仓 Delta = 0）。
2. **稳定赚取资金费率差（纯吃利息）**：
   - 币圈永续合约每 1 小时或 8 小时结算一次资金费率（Funding Rate）。
   - 当两家交易所之间出现费率差异，或者多头整体支付高额费率时，机器人每期稳定收取利息。
   - 历史平均年化收益率（APR）通常在 **15% ~ 50%**。

### 为什么适合普通散户和家庭网络？
- **不拼毫秒级延迟**：持仓周期通常为数天甚至数周，几秒钟的网络波动对策略毫无影响。
- **不受牛熊市限制**：牛市多头疯狂加杠杆付高息，熊市两所费率分化，都有稳定套利空间。
